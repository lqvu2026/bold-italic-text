# Bold Italic Text

Make bold and italic text to paste into Facebook or LinkedIn posts. Vietnamese friendly.

Type your text, style the words you want, and copy.

## How to use

1. Type or paste your text.
2. Select some words and tap **Bold**, **Italic** or **Both**. With nothing selected, the whole text is styled.
3. Pick **Sans** or **Serif** lettering.
4. Tap **Copy**, then paste into your post.

You can also type the markers yourself: `**bold**`, `*italic*`, `***bold italic***`.

## Notes

- The styled letters are Unicode characters, not real formatting, so they work anywhere text can be pasted.
- Vietnamese accents are kept. The letter đ has no styled version and stays plain.
- Italic has no styled digits in Unicode, so numbers stay plain in italic.
- Screen readers may read styled text poorly. Use it for a few key words.

## Publishing (GitHub Pages)

Files: `index.html`, `bold-italic-text-icon.png` (180x180 Home Screen icon, linked as `apple-touch-icon`), this README.

Commit them to the repo, wait 1-2 minutes for Pages, then Add to Home Screen. If an old shortcut shows a placeholder, delete it, quit Safari, reload, and add it again.
